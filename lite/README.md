# AerioTV Lite

App mínima para Android TV antiguos: lee una lista M3U (la misma del Roku) y la guía de
`JXRiquelme/guia-tv`, y parte reproduciendo Canal 13.

- ▲ / ▼: cambiar de canal · números: ir directo · OK: lista de canales · ◀ ▶: información
- Atrás dos veces: salir

El APK se compila solo con GitHub Actions y queda en Releases (`lite`).

Versión actual: 1.8.1
